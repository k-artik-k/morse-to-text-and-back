# Morse Code Translator

A simple web-based Morse code translator for converting text to Morse code and Morse code audio back to text.

**Live Website:** [MORSEEE](https://k-artik-k.github.io/morse-to-text-and-back/)

### Features
- Text to Morse code conversion.
- Morse code to text decoding.
- Audio playback with adjustable spacing.
- Download Morse code as WAV audio.
- Visual representation of Morse signals.

### Usage
Visit the [website](https://k-artik-k.github.io/morse-to-text-and-back/), enter your text, and play or download the generated audio. Switch to Morse to Text to decode a WAV file.
